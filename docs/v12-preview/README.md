# AMM v12 preview

These screenshots use synthetic resume, job, and account data from the local dashboard harness. They show the proposed interface before release; no personal profile or live job-site session was used.

## First-run flow

1. **Welcome:** a short explanation of the three steps. [Screenshot](v12-01-welcome.png)
2. **Resume:** choose a PDF, DOCX, Markdown, or text file. [Screenshot](v12-02-resume.png)
3. **Searches:** AMM suggests terms from the scanned resume; add or remove terms before continuing. [Screenshot](v12-03-search-suggestions.png)
4. **Preferences:** choose a workplace, optional location and name, and search time. Less common filters stay under More preferences. [Screenshot](v12-04-preferences.png)
5. **Job feed:** start with Dice immediately, or [prepare hiring.cafe](v12-05b-both-sources-ready.png) in a browser to use both. Finish opens the dashboard; **Scrape now** starts the first batch. [Screenshot](v12-05-start-searching.png)

## Main workspace

| Screen | What changed |
| --- | --- |
| [My matches](v12-06-my-matches.png) | Clear shortlist summary and primary Scrape now action |
| [Searches](v12-07-searches.png) | Search terms first; blocked companies and career boards tucked under optional sections |
| [My resume](v12-08-my-resume.png) | Resume evidence and suggestions in the same workspace |
| [Settings](v12-09-settings.png) | Everyday controls first; detailed filters and AI in disclosures |
| [Advanced settings](v12-11-advanced-settings.png) | Optional matching controls remain available |
| [Connections](v12-10-connections.png) | App status, job-site sign-in, Telegram, and email in one place |

The harness verifies the quick-start setup payload, the return to an unfinished setup, and the existing dashboard checks. These screenshots confirm the local interface with synthetic data. Live hiring.cafe, Telegram, Gmail, and updater paths were not exercised for this preview.
